# DBK (Darth Beltazar's kit)

[English](README.md) | **Русский**

Аддон для Meteor Client под Minecraft 1.21.4 (на основе https://github.com/MeteorDevelopment/meteor-addon-template)

## Как использовать

- положить в папку mods (нужны Meteor и Baritone; для установки блоков в воздух Baritone'ом см. [ниже](#air-place-для-baritone))

## Модули

### AutoBottle
Автоматически пьёт зловещие бутылочки для фарма рейдов
### AutoFirework
Автоматически использует фейерверки для ускорения полёта на элитрах
### DBKAirPlace
Ставит блоки в воздух (свой модуль, потому что AirPlace уже есть в Meteor Client).
Его настройка `baritone-air-place` позволяет и Baritone ставить блоки в воздух, см. [Air place для Baritone](#air-place-для-baritone).
### EnoughLight
Подсвечивает места спавна мобов (по уровню освещённости и окружающим блокам)
### PointsAutoWalk
Автоматически идёт к заданным точкам с помощью Baritone
### WoodMine
Добывает дерево с помощью Baritone

## Air place для Baritone

С этой функцией Baritone ставит блоки прямо в воздух, без опоры, так же как DBKAirPlace:
- **при ходьбе** (`#goto`, `#path`, `#tunnel`, PointsAutoWalk, ...): мосты строятся без приседания и установки блока назад под себя, и он может подняться на блок, рядом с которым ничего нет;
- **при строительстве** (`#build`, `#sel fill`, `#sel replace`, ...): висящие в воздухе блоки схематики или выделения ставятся с любой точки в пределах досягаемости, там где обычный Baritone застревает.

Сервер должен разрешать установку блоков в воздух (как и для самого DBKAirPlace).

### Установка

Нужен [форк Baritone от DBK](https://github.com/DarthBeltazar/baritone/tree/dbk-airplace) вместо Baritone от Meteor.

1. Скачайте `baritone-unoptimized-fabric-<версия>.jar` из [релизов форка](https://github.com/DarthBeltazar/baritone/releases) и положите его в папку mods.
   Нужен именно **unoptimized**: standalone-версия обфусцирована, а Meteor обращается к Baritone по настоящим именам классов.
2. Удалите из папки mods jar Baritone от Meteor (`baritone-meteor`): в обоих лежат одни и те же пакеты `baritone`.

Собрать самому (нужен JDK 21), jar появится в `fabric/build/libs/`:
```
git clone -b dbk-airplace https://github.com/DarthBeltazar/baritone.git
cd baritone
./gradlew :fabric:build
```
Новый релиз публикуется пушем в форк тега вида `v<версия>-dbk.<n>` (например, `v1.13.1-dbk.2`), см. `.github/workflows/dbk_release.yml` в форке.

С Baritone от Meteor DBK тоже работает, просто без этой функции: при включении настройки появится предупреждение.

### Использование

1. Включите модуль **DBK-air-place**.
2. В его группе **Baritone** поставьте галочку **baritone-air-place**.
3. Пользуйтесь Baritone как обычно (`#goto ~ ~ ~20`, `#sel fill stone`, ...).

Если снять галочку (или выключить модуль), Baritone сразу вернётся к обычному режиму: путь, по которому он идёт, будет перестроен без установки в воздух.

Под капотом галочка переключает собственную настройку форка `airPlace`, так что работают и команды `#airPlace true` / `#airPlace false`, даже без DBK.
Пока модуль включён, главнее галочка.

### Какие блоки он тратит

- На мосты и ступеньки Baritone сначала берёт блоки из `acceptableThrowawayItems` (по умолчанию земля, булыжник, незерак, камень).
  Если их нет, он берёт любой другой полный блок из инвентаря, кроме сыпучих (песок, гравий, цементный порошок)
  и блоков с содержимым (сундуки, шалкеры, печки, ...). Ценные блоки вроде алмазных тоже пойдут в ход, так что не держите их в хотбаре.
- При строительстве он, как обычно, ставит те блоки, которые требует схематика.

### Советы

- Интервал между установками задаёт настройка Baritone `rightClickSpeed` (по умолчанию 4 тика). Увеличьте её, если сервер кикает за слишком частую установку.
- Блок появляется только после подтверждения сервером, поэтому при большом пинге Baritone немного ждёт у края (присев, так что не упадёт).
- Паркур-прыжки с установкой блока в полёте не используют установку в воздух.

### Разработка

`./gradlew runClient` сам подхватывает форк, если он собран рядом с этим репозиторием (`../baritone`), иначе используется Baritone от Meteor.
После изменений в форке пересоберите его там командой `./gradlew :fabric:build`.
